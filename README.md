# Profile Page

## Overview
This project is a personal profile web page that showcases information about me while demonstrating core front-end development skills such as layout design, form handling, and multimedia integration.

## Features
- Personal profile section (About Me + profile picture)
- Fully styled user interface using CSS
- Sign-up form with validation for required fields
- Embedded audio playback
- Embedded video with controls (mute, download)
- Organized media content (images, audio, video)

## Purpose
The goal of this project was to practice and demonstrate:
- HTML page structuring
- CSS styling and layout design
- Form creation and validation
- Integration of multimedia elements in web pages

## Technologies Used
- HTML
- CSS

## Project Structure
- `index.html` – Main profile page  
- `media/` – Contains images, audio, and video files  
- `styles.css` – Styling for the page  

## How to Run
1. Clone or download the repository  
2. Open `index.html` in your browser
